How do I enable live On-Device AI in my browser?

To run these demos using the native models built into Google Chrome, configure these flags:

  1. Open Chrome and navigate to chrome://flags/#prompt-api-for-gemini-nano. Set it to Enabled.
  2. Navigate to chrome://flags/#optimization-guide-on-device-model. Set it to Enabled BypassPerfRequirement.
  3. Navigate to chrome://flags/#translation-api (or writing-assistance APIs) if you want support for specialized translation, writing, and rewriting on-device models.
  4. Restart Chrome. The browser will download the model in the background (check progress at chrome://components under Optimization Guide On Device Model).
